Lego Store

A full-stack e-commerce web application simulating an online Lego retail store, built with Flask, MySQL, and HTML/CSS/JS. Covers the whole pipeline — customer-facing shopping through to backend inventory and order management.

- Built a full-stack e-commerce platform end-to-end: user authentication, a product catalog, a shopping cart, and an admin dashboard for managing inventory and orders
- Designed a normalized MySQL schema spanning 8+ tables, with atomic transactions to validate stock and keep data consistent under concurrent purchases
- Built real-time admin analytics surfacing product popularity and order history across 500+ records, with strategic indexing to speed up catalog search
